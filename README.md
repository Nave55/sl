# sl (custom std library for c++)

## Uses C++ 26

### Aim is to provide a std library which improves compile times and allows for use of custom allocators

**Currently Contains:**

- **Custom Allocators** - Arena, Pool, Stack, Heap, Tracking
- **Custom Pmr Allocator** - Arena
- **Array** - Array<T, N>
- **Fixed Dynamic Array** - Fixed_Vector\<T, N>
- **Dynamic Array** - Vector\<T>
- **Hash Table** - Hash_Map\<K, V>
- **Hash Set** - Hash_Set\<V> 
- **Dynamic String** - String
- **Fixed Size String** - Str\<N>
- **Pair** - Pair<T1, T2>
- **Vec** - Vec2<T>, Vec3<T> 
- **Tuple** - Tuple<T..>
- **Smart Pointers** - Unique, Shared, Weak, Intrusive
- **Memory Tracking**
- **Extra Tools**
